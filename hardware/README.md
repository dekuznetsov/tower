## Призначення GPIO

| GPIO | Режим | Підключення | Опис |
|------|-------|-------------|------|
| GPIO 18 | PWM Output | IRF520 SIG | Керування насосом (LEDC ch0, 5000 Hz, 8-bit) |
| GPIO 34 | ADC Input | Moisture Sensor AOUT | Аналогове зчитування вологості (0–4095) |
| GPIO 19 | Digital Input | XKC-Y25 OUT | Рівень води (HIGH = низький рівень = небезпека) |

> **Важливо:** GPIO 34 на ESP32 — це вхід тільки для читання (input-only), що ідеально підходить для ADC. Не використовуйте GPIO 34 як вихід.

## Примітки щодо монтажу

### MOSFET IRF520
- Модуль IRF520 має вбудований резистор затвора (R_gate) та захисний діод.
- Сигнал PWM 3.3V з GPIO 18 достатній для відкриття затвора IRF520.
- **Спільна земля обов'язкова:** GND ESP32 і GND 12V шини мають бути з'єднані.
- Встановіть конденсатор 100 мкФ паралельно до живлення насоса для придушення імпульсних перешкод.

### Датчик вологості v1.2 (капацитивний)
- Живиться від 3.3V або 5V (рекомендується 3.3V для прямого підключення до ADC ESP32).
- Аналоговий вихід AOUT: ~4095 = сухо, ~1500 = занурений у воду.
- Занурюйте тільки нижню частину датчика (до лінії позначки), не занурюйте електронну частину.

### XKC-Y25 (безконтактний датчик рівня)
- Живиться від 5V.
- Вихід OUT — цифровий, активний HIGH: HIGH = рівень рідини нижче датчика.
- Прикріпіть датчик зовні до стінки резервуара на мінімальному рівні води.
- Товщина стінки резервуара не повинна перевищувати 4 мм для надійного спрацювання.

### Захист від вологи
- Розмістіть електронну плату в пластиковому корпусі.
- Виведіть дроти датчиків через кабельні введення з ущільнювачами.
- Не розміщуйте ESP32 та MOSFET модуль безпосередньо над водою.

## Посилання на прошивку

Конфігурація GPIO визначена у `firmware/src/config.h`:

```cpp
#define PUMP_GPIO        18   // PWM вихід → IRF520 SIG
#define MOISTURE_PIN     34   // ADC вхід → Moisture Sensor AOUT
#define WATER_LEVEL_PIN  19   // Digital вхід → XKC-Y25 OUT
#define PWM_CHANNEL      0    // LEDC канал 0
#define PWM_FREQ         5000 // 5000 Hz
#define PWM_RESOLUTION   8    // 8-bit (0–255)
```
